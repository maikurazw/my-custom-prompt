# 🐍 1. Python Custom Prompt

A custom command line prompt built with Python, specifically tailored for the Windows environment.

## Features
- Displays the current directory as `C:\path\to\dir> `
- `cd` command to change directories (supports paths with spaces)
- `cat` / `type` commands to read and display text files
- Automatically passes unknown commands to the native Windows shell

## How to Run

1. Make sure you have Python installed.
2. Open your terminal or Command Prompt.
3. Navigate to this directory:
   ```bash
   cd 1-python
   ```
4. Run the script:
   ```bash
   python main.py
   ```
